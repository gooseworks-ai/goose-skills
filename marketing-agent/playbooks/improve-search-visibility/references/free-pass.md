# The free pass

Load at step 1. Everything here costs no credits. Do all of it before the first message to the marketer; never stop after one source to ask "go deeper?". Work through the host's own tools: browser, web search, fetch or shell — reading public pages that way is allowed (AGENTS §8).

## Order (cheapest and most decisive first)
1. **The brand's own side.** Brain summary, products, approved claims status, past search runs; the homepage, pricing, about and the 3–6 pages nearest the buying questions (title, first paragraph, what it says the product is); robots.txt and sitemap.
2. **Draft the question set** (`question-list.md`) from what you just read plus customer words and the rivals' pages. No approval needed to run it; the marketer edits it afterwards.
2b. **Read the positioning the site sells today** — if more than one buyer or positioning shows, note each for the "which buyer" decision; never pick one.
3. **ChatGPT, signed out, in the host browser** — every question once, key questions three times (`citation-protocol.md` for the settings and the wait rule). This is the headline of the first message.
4. **Google AI Overview and AI Mode in the same browser**, when Google lets the browser in. If navigation is refused or a challenge page shows, stop that surface and mark it "not checked — Google blocked the browser"; never solve a challenge.
5. **Web search for each category question** (the host's search tool): which lists, threads, videos and vendor pages come up. Label it "web search" — it is not Google's exact page one (that's the paid top-up).
6. **News and mentions, web search:** the brand and each main rival — launches, funding, press, reviews, "vs" pages, listicles that name them, in the last 12 months.
7. **Profiles answer engines read** (`entity-and-local.md`): the five that matter for this business type, read like a person would; never G2, Capterra, Trustpilot or Amazon by script.
8. **App store**, only if there is an app: Apple's public search lookup, then the listing (`app-store-listing.md`).
9. **Foundation** (`foundation-check.md`): crawler access by bot, CDN blocking (needs a shell), duplicate domains, structured data on the checked pages, and any large templated page set in the sitemap (sample it).
10. **Demand evidence** (`page-map.md` Demand): Google Trends and autocomplete for each cluster in the browser; say "no demand data" where there is none.

## Hosts without a browser
ChatGPT, AI Overview and AI Mode can't be asked. Do everything else, say plainly in the first message that the AI answers weren't checked, and offer the short paste set (`citation-protocol.md`) as one of the decisions.

## What the free pass must produce
- Per question: ChatGPT named yes/no (k of N), who is named instead, which sources it cited.
- The pattern in one sentence.
- Draft five fixes, each in one plain line.
- What wasn't checked and why.
