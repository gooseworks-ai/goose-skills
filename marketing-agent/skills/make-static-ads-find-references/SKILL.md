# find-references

**Read:** the selected concepts and checked own-ad/history inventory. **Write:** compared reference_options and selected template ID in run.json; show picks with the concept plan. `../make-static-ads/references/workflow.md` owns the shared record shape.

1. Inspect available imported competitor statics, then3–5category leaders (about20ads each), then query the library for slots leaders cannot fill. Record inaccessible sources and stopping reasons. `references-and-remix.md` §2 supplies lookup routes; a genuine host block is reported, never bypassed. Library run length stays unknown.
2. Keep three useful candidates from three advertisers per concept. View each image and open its detail before suggesting it. Reject fixtures, placeholder brands, illegible or infeasible treatments. Reuse a concept's shortlist across its executions; a new search is useful when it adds a missing relationship/look, not as ritual.
3. State what each contributes: layout, mechanism or craft. Direct competitors supply layout only. Choose the reference that serves the authored concept; preserve its reason/persona/proof. A craft-only choice requires the concept's own meaningful event, not a borrowed mood labelled as an insight.
4. Show the gallery when the marketer wants to choose. “Your choice/finals only” → show the selected image/advertiser in the plan instead. Record why each loser was rejected. Spread suggestions across advertisers and looks; compare with checked history and qualify novelty.
5. Register unregistered references through media_upload/ads_template_create and read their actual details before compose. Confirm ownership explicitly. Other brands' pixels stay out of generation in every role; an owned layout reference may be attached, mechanism/craft remains written direction. Record the actual source URL/type and known or unknown run dates.

No-headline reference only when deliberately chosen for a textless treatment. Missing inputs for a review, founder note or software screen → choose another feasible treatment. Blueprint extraction is needed for a layout reference only; mechanism/craft uses the authored scene. See references-and-remix §5 for direct-competitor abstraction and side-by-side checks.
