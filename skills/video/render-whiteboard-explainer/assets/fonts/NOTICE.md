# Fonts bundled with render-whiteboard-explainer

The renderer letters the board with these two faces. They ship with the skill so a run does
not depend on what happens to be installed on the machine.

| File | Family | Licence | Source |
| --- | --- | --- | --- |
| `PermanentMarker-Regular.ttf` | Permanent Marker, by Font Diner | Apache License 2.0 | https://fonts.google.com/specimen/Permanent+Marker |
| `TitanOne-Regular.ttf` | Titan One, by Rodrigo Fuenzalida | SIL Open Font License 1.1 | https://fonts.google.com/specimen/Titan+One |

The caption pill uses Segoe Script Bold when Windows has it. That face is Microsoft's and is
not redistributable, so it is not bundled; everywhere else the caption falls back to
Permanent Marker.
