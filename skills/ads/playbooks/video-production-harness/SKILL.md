# Human version

Create and revise videos using a sourced brief, inspected assets, intentional
voice and coherent visual proof. Review the story, execution and final files at
the appropriate stage. Preserve earlier cuts and the decisions needed to resume.

---

# Agent version

This is the full production sequence used by Studio and customer video hosts. The host supplies its connection instructions; the production decisions and detailed steps live here once.

Read `capabilities.md`, the host binding and `orchestrator.md` before starting. The host binding is the entry skill that loaded this package (for GooseWorks: make-custom-video). Then read each detailed step when the sequence enters it. A missing capability, approval or dependency blocks that operation; do not invent a tool or substitute a successful status.

Before planning scenes, open [the shot-routing guide](references/shot-routing.md) and the genre card it names for the brief (AI creator UGC, motion graphics, hypermotion, chat UI or product demo). Open them again when making or re-rolling a clip.

Read [the editorial review guide](references/editorial-review.md) before reviewing
or revising a cut. It connects stage decisions, exact-version notes, change impact,
per-output finishing and editable history to the existing project records.

Read [creative contract and review](references/creative-contract-and-review.md)
before reference study, handoff and final review. It defines complete audiovisual
coverage, content-derived duties, clip eligibility and exact-file evidence.
Read [speech and route qualification](references/speech-and-route-qualification.md)
before choosing voice/model or editing speaking footage; read
[product scale and world](references/product-scale-and-world.md) when product size,
use or capacity matters. Use [libraries, look and rubric](references/libraries-look-and-rubric.md)
for character, sound, camera, lighting and overlay choices.

Keep the two mandatory owner gates: script and ingredients. Agent checks add no
automatic human review round. Missing actual listening or motion remains incomplete;
a technical pass cannot approve content. Exclude failed clips from passing assembly.

The sequence accepts a brief with an optional reference. References supply creative direction. New production still requires current script and ingredient approval, controlled spend, inspection of every clip and review of the actual final export.

The portable scripts provide local assembly and technical evidence. Their successful exit does not approve visual quality, spoken copy, captions, product identity or the final creative.

For an existing-footage request, use the selected host's search and actual-frame inspection, freeze the original identity/revision/excerpt/audio in the script and ingredients, and follow the same approval gates. Read the stored-footage contract in `capabilities.md` before consumption. A selected existing original does not authorize buying a generated replacement.
