# Video production harness

This is the full production sequence used by Studio and customer video hosts. The host supplies its connection instructions; the production decisions and detailed steps live here once.

Read `capabilities.md`, the selected host binding and `orchestrator.md` before starting. Then read each detailed step when the sequence enters it. A missing capability, approval or dependency blocks that operation; do not invent a tool or substitute a successful status.

The sequence accepts a brief with an optional reference. References supply creative direction. New production still requires current script and ingredient approval, controlled spend, inspection of every clip and review of the actual final export.

The portable scripts provide local assembly and technical evidence. Their successful exit does not approve visual quality, spoken copy, captions, product identity or the final creative.

For an existing-footage request, use the selected host's search and actual-frame inspection, freeze the original identity/revision/excerpt/audio in the script and ingredients, and follow the same approval gates. Read the stored-footage contract in `capabilities.md` before consumption. A selected existing original does not authorize buying a generated replacement.
