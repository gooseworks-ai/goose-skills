# Human version

A new opening must lead into the body's real proof and payoff. Keep a compatible hook test local to the opening; a new promise needs a script/body proposal. Review visual restyles too, and compare complete videos before choosing.

Use the existing [[composes::render-hook-replacement]] implementation and [[composes::create-hook-variant-pack]] when actually available. This guide supplies editorial decisions; it does not duplicate their renderer or storage contract.

# Agent version

## Check availability and meaning before media spend

Fetch the current hook package and read its actual returned scripts/config/reference guide. An empty/not-found catalog response blocks that requested renderer route before generation. A local source checkout or open change is not proof the served capability exists. Preserve the proposal and identify the missing publication; offer a supported ordinary recut only as an explicit changed plan, not an imitation renderer. Record the fetched version/content hash on the existing capability plan.

Freeze the exact watched original/version/checksum and inspect its full body, actual speech, caption boundaries and ending. Save the baseline promise, buyer, mechanism, visible proof and payoff. Each opening idea names the hypothesis, changed image/action/audio/text and expected link into the retained body.

| Classification | Decision before execution |
| --- | --- |
| Same promise and proof, different opening treatment | An isolated opening test may preserve the exact body/source. Establish a measured safe hook boundary and use the existing replacement package's preflight/config. |
| New promise, buyer, mechanism or outcome | Identify unsupported body/proof/payoff beats and propose concrete script/coverage changes first. Return to script/design gates; label any resulting output a broader recut. Do not splice an attractive incompatible hook. |
| Same words, changed visual/action/audio | Still review the changed opening and its meaning. A product/action restyle can imply a different benefit even when the transcript is identical. |

Example: “Stop copying campaign results” can lead to a body demonstrating an automatic report. “Know where to spend the next dollar” needs evidence of useful budget guidance; report export alone does not satisfy that promise. Keep the first supported hook or propose the additional supported proof/script, rather than imply a capability absent from the body.

## Shortlist, render and compare

1. Prepare up to three cheap text/shot sketches within the authorized direction, with hypothesis, body compatibility and incremental cost. Preserve explicit user copy and selected idea. A recommended creative is not a performance winner.
2. Run the fetched replacement implementation's real free preflight against the exact source and measured cut/words/captions before creating a paid opening. Preserve original and use unique candidate paths/labels. For new generated media, quote only that opening and apply current approval limits.
3. Read actual renderer preservation evidence. Confirm retained body frame order, audio, captions and ending, measured duration delta and speech/caption boundary checks. Encoding comparisons do not replace perception. Do not invent a passing manifest for an unsupported route.
4. Play every complete candidate at full speed and listen to opening, join, retained body and ending. Record received message, hook-to-body transition, truthful proof/payoff, readable text and actual output checksum. A visual-only restyle repeats this opening review even if its script is inherited.
5. Compare complete variants with baseline, retain strengths and explain tradeoffs. Save exact source lineage, hypothesis, technical evidence, perceptual status and selected-versus-candidate decision in existing version/history records. No final overwrite or automatic selection.

Missing playback/listening or unresolved compatibility leaves review incomplete. Use the current bounded review/repair loop; unresolved concept changes return to script/production rather than consuming repeated opening generations. Audience performance stays unknown until actual attributed results exist.
