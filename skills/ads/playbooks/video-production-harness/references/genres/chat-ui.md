# Chat UI

A story told as a phone chat, or a question answered in an AI chat. Routing rows are named as in the shot-routing guide.

## Shot list skeleton
1. 0-1.2 s framed phone; the first message is sent by 1.2 s.
2. Hook: the photo or line the chat is about.
3. Banter: quick replies, typing dots before each received text.
4. Reveal: the product or offer in a message.
5. About 0.6 s pause, the last message, about 0.6 s hold.
6. 0.3 s crossfade to a static end card, 2.5-3.5 s.

AI chat instead: the question types in, send, one grey dot for about 0.5 s, the answer streams in word by word, 1 s hold.

## Routing rows
Chat screen · Kinetic type / motion card · Music · End card.

## Pacing
- 7-14 messages over 15-45 s; reactions 0.25-0.45 s apart, sentences 0.6-0.9 s, typing dots about 0.7 s.
- AI chat: question at most 16 words; answer 40-75 words at about 7 words/s; 11.5-21 s.

## Nearest template
`imessage` (AI chat: `chatgpt`)

## Top 5 failures and fixes
- Flicker at scene joins → record one continuous take; the only cut is to the end card.
- Sound on typing or thinking dots → keep them silent; sound only when a message lands.
- The AI chat looks like another app → one grey dot; stream words, not letters; send, keyboard down and header change in one beat.
- An attached screenshot looks generated → rebuild the real app's layout, colours and type in HTML.
- The end card drifts or fakes the logo → static card, real logo; star ratings only with brand proof.
