# Human version

Keep the approved brief intact when a specialist makes a scene. Fetch the actual package, prove its required tools work, pass exact source and timing choices, and check what comes back. Reuse valid approved work after an interruption.

This is a handoff inside the existing production sequence. Existing project artifacts and package metadata carry it; it is not a new renderer, API or manifest schema.

# Agent version

## Select and bind before execution

Read the fetched content, scripts, files, dependencies, version/content hash and the selected connection's real tool schemas. Save the package identity in the existing capability plan and keep the exact package in the run workspace. Package presence is not runtime readiness. Run free checks from that package's documented cwd: real media probe, imports/CLI dry run, fonts/encoders and an actual browser launch/close when selected. Missing dependencies block that route before provider/upload/generation calls. A local helper that cannot carry required project ownership/billing context is unavailable for paid work.

The routes below are starting points to discover, not promises of installation. Search/fetch current slugs and inspect the returned implementation. No undocumented author directory may be required.

## Handoff checklist on existing records

Before each specialist runs, resolve and record these values in the current capability plan/scene record or a linked project artifact:

- Exact brief revision and sourced creative-brief pointer; product/variant, supported claims and locked user copy. The same brief reaches writer, scene planner and renderer.
- Approved script revision and exact line/on-screen wording, stable scene/beat IDs and numeric start/end/duration; distinguish planned timings from measured speech timings.
- Selected input asset/take IDs, checksums and source excerpt ranges; separate production material from truth/style references and keep locked choices.
- Approved voice/native-dialogue strategy, selected performance/settings, pronunciation, pause/emphasis intent; no second narrator over native speech.
- Visual/world references, crop/layout, ratio, text space, transition/neighbor requirements and output expected for this phase.
- Selected package slug/version/content hash, executable path relative to that package, real supported tool/model/schema and dependency identities; existing approval revision, quote/budget and provider operation identity.
- Expected output roles: media, editable sources, measured timings, provider/job provenance and the checks needed before assembly. Do not invent required wire fields; map to the binding's real schema.

Review outputs against exact creative_contract_revision, package/source hashes and handoff inputs, not status. Probe bytes, inspect complete action/product/scale/identity and hear full speech/mix; check exact drivers/timings, ratio/duration and proof. Save per-duty pass/needs_revision/incomplete. A stale source, failed candidate, missing word, wrong product or unconfirmed URL blocks passing assembly.

## Resume and repair

Load authoritative project state before invoking a specialist. Match source/script/asset/package fingerprints, host approval revision and saved completed jobs. Probe the approved media, retain its exact IDs/hashes and run only missing/invalid work. Existence alone is insufficient: several specialist helpers skip any existing filename, including invalid bytes. Validate first; restore the correct saved version or label a new repair, never regenerate all scenes because the process restarted.

Poll known unresolved jobs before any retry. Changed direction, provider, inputs or cost uses the affected existing approval gate. If an unsupported motion dependency is required, record the missing dependency and offer a concrete compatible plan (for example, approved still plus local pan); do not silently downgrade the effect or spend hoping it works.

## Acceptance boundary

A fixture dry run proves input mapping and a local returned artifact proves that narrow renderer path. Neither proves paid generation, human approval or a served host end-to-end run. Report fetched package identities separately from edited source revisions. New source changes are not served until the actual catalog returns their matching versions/hashes.
