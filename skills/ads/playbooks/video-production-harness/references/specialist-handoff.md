# Human version

Keep the approved brief intact when a specialist makes a scene: fetch the real package, prove its tools work, pass exact sources and timings, check what comes back, and reuse valid work after an interruption.

# Agent version

## Select and bind before execution

Read the fetched package, its dependencies, version/hash and the real tool schemas; save its identity in the capability plan. Presence is not readiness: run free checks from its documented cwd (media probe, CLI dry run, fonts, a real browser launch when selected). A missing dependency blocks that route before any paid call. A helper that cannot carry project billing cannot do paid work.

## Handoff checklist

Record before each specialist runs:

- Brief revision, product/variant, supported claims and locked copy. The same brief reaches writer, planner and renderer.
- Approved script revision, exact lines and on-screen words, scene IDs with start/end; planned versus measured timings.
- Asset/take IDs, checksums and excerpt ranges, apart from style references.
- Voice or native-dialogue strategy; never a second narrator over native speech.
- References, crop, ratio, text space and neighbour requirements.
- Package slug/version/hash, tool and model, approval revision, budget.
- Expected outputs: media, editable sources, measured timings, job provenance.

Review the output against the creative contract and these inputs, not the specialist's success status. Probe the bytes; check duration, copy, proof, action, product, scale and identity; listen to each spoken output when your tools can, otherwise record `measured`. Save pass, needs_revision or incomplete per duty. A stale source, wrong beat, missing word, wrong variant or unconfirmed provider URL blocks assembly.

## Resume and repair

Load saved state and match fingerprints, approvals and completed jobs. Run only missing or invalid work; some helpers skip any existing filename, even bad bytes, so validate first. Never regenerate every scene because a process restarted. Poll unresolved jobs before a retry. A changed direction, provider, input or cost goes back through the affected approval. A missing motion dependency gets a compatible plan (a still plus a local pan); never spend hoping it works.

## Acceptance boundary

A dry run or local artifact never proves paid generation, approval or a served end-to-end run.
